# Live Keys

Етапи 0–3: до **чотирьох шарів**, **29 тембрів у 7 категоріях** і **10 worship-пресетів**.
Семплерні роялі та Felt Piano з трьома рівнями velocity, семпльовані педи, FM-електропіано, синтезовані органи й ліди.
Split/velocity ranges, transpose, mono/glide, sustain, pitch bend, CC1/CC11.
Filter/chorus/reverb/delay/EQ, sample-peak limiter, stereo/mono output і Panic.
Власні пресети, чернетка, IndexedDB, JSON export/import. Angular standalone +
Signals, strict TypeScript, native Web Audio/Web MIDI. Backend не потрібний.

## Запуск

Потрібен Node.js 24 (від 24.15, перевірено інструменти з 24.21.0), npm,
настільний Google Chrome на Windows/macOS. Підтримка macOS і фізичного MIDI
**потребує ручної перевірки**. Мобільний браузер/iPhone не є підтриманою MIDI-платформою цього зрізу.

```sh
npm ci
npm start
```

Відкрийте http://127.0.0.1:4200. Локальні семпли включені в репозиторій.
`npm run samples:verify` перевіряє SHA-256; `npm run samples:fetch` відновлює їх
із зафіксованого upstream commit (потребує мережі). Не запускайте HTML через file://.

## Перша гра

1. Натисніть **Увімкнути звук**, дочекайтеся **Звук готовий**. Підготовка завантажує
   і декодує 48 семплів нового банку, якщо серед шарів є рояль. Синтез не потребує семплів;
   під час note-on мережі немає.
2. Відкрийте **MIDI → Дозволити MIDI**, дозвольте доступ браузеру, позначте потрібні входи.
   SysEx не запитується. Можна грати без MIDI на екранних клавішах.
3. Грайте; MIDI-педаль CC64 утримує ноти. Master регулює загальну гучність,
   мінімум −60 dB означає повну тишу. Спробуйте 32 голоси на слабшому пристрої.
4. **Panic** або Escape завершує голоси та хвости ефектів коротким fade, скидає sustain і контролери.
   Після нього можна відразу грати. Якщо фізична педаль ще натиснута,
   відпустіть і натисніть її повторно.
5. Після від’єднання зупиняються лише ноти цього MIDI-входу. При повторному
   підключенні виберіть його знову; автоматичного неоднозначного призначення немає.

Комп’ютерні `A W S E D F T G Y H U J K` грають C4–C5, незалежно від розкладки.
Екранна клавіатура має 88 клавіш A0–C8 (52 білі та 36 чорних).
На вузьких екранах вона прокручується горизонтально.
Enter/Space на сфокусованій екранній клавіші також грають ноту. Втрата фокуса
звільняє локальні ноти й sustain, але не припиняє фізичний MIDI без потреби.
Екранної кнопки sustain немає; MIDI-педалі незалежні по входу/каналу.

Звук виходить через системний аудіопристрій комп’ютера, а не через MIDI-кабель.
Виберіть дротові навушники/інтерфейс у налаштуваннях ОС. ASIO/buffer-size UI немає.
При suspend/sleep натисніть **Відновити звук**. Безперервність у фоні не гарантується.

## Piano + Pad, split та свої пресети

1. Натисніть **+** у порожній картці шару, потім виберіть тембр. Warm Pad має повільну атаку, два detuned осцилятори,
   ADSR та low-pass. Зменште гучність другого шару, налаштуйте атаку, затухання
   й яскравість. Доступно до чотирьох шарів із будь-якою комбінацією 30 тембрів.
2. Для split задайте роялю ноти 0–59, педу 60–127. MIDI 60 = C4. Обидві межі
   включені; якщо поставити 60 в обох шарах, ця нота звучатиме обома тембрами.
3. **Ноти та динаміка** відкриває split і velocity; **Характер звуку** — envelope/mono/glide.
   MIDI-входи обираються у загальному вікні **MIDI**; фізична педаль sustain працює без окремої секції в картці шару.
4. Mute і Solo взаємовиключні в межах шару; кілька Solo в різних шарах дозволені. Mute/видалення
   завершує голоси шару коротким fade. Увімкнення не повторює старі ноти.
   Split, transpose, fine tune та velocity curve діють на **нові** натискання;
   старі ноти отримують свої note-off/sustain release. Gain, pan і cutoff згладжуються.
   Pad attack/release беруться при створенні голосу; зміни застосовуються до нових нот.
5. **Зберегти як** відкриває поле назви у головній панелі, без модального вікна.
   Початкова назва складається з інструментів; її можна змінити перед **Створити**.
   **Зберегти** перезаписує вибраний користувацький пресет. Для заводського спершу
   створіть власну копію через **Зберегти як**. Нумерація списку автоматична,
   після 10 заводських пресетів; номер не є частиною назви. Видалення вимагає підтвердження
   в інтерфейсі; поточний звук/чернетка залишаються доступними.
6. Незбережені зміни позначені й автозберігаються окремою чернеткою через 300 ms.
   Перемикання пресету відбувається без підтвердження й замінює поточну чернетку;
   щоб залишити редагування, натисніть **Зберегти** перед перемиканням.
   Дочекайтеся **Чернетку збережено локально** перед закриттям. Відновлення даних не
   запускає звук автоматично. Master/voice limit/global transpose зберігаються окремо;
   MIDI-входи після перезапуску потрібно підтвердити вибором знову.
7. **Експорт JSON** включає збережені пресети, окрему копію поточної чернетки, settings
   і список банків; семпли не включаються. Імпорт перевіряє весь файл, додає копії
   з новими IDs, не перезаписує наявні пресети й не застосовує settings із файлу
   до master/MIDI/global transpose. Підтримується лише поточна schemaVersion 3 та актуальні тембри.

Файл до 1 MiB/100 записів; бібліотека до 99 збережених пресетів, щоб залишити місце
для чернетки в експорті. Невідомі інструменти/версії, некоректні значення й відсутні
банки відхиляються. Запис імпортованих пресетів — одна транзакція. Помилки quota або
доступу до сховища показуються; гра й експорт залишаються доступними. IndexedDB може
бути очищена браузером — використовуйте JSON-копії. Незавершений запис перед негайним
закриттям вкладки не гарантований. У кількох вкладках останній запис чернетки перемагає.

Перемикання підготовляє новий пресет до активації. Поточний звук зберігається при
помилці; старі ноти можуть завершуватися після переходу. Обмеження — поточний і два
попередні екземпляри; найстаріший завершується fade. Повного effect spillover ще немає.

## Бібліотека та ефекти

Gentle Flute — синтезований флейтовий лід, mono із м’якою атакою та коротким glide.
Brash Mono Lead — синтезоване наближення за спектром наданого MP3: пилка й
прямокутна хвиля октавою вище, швидка атака, короткий glide, два осцилятори.
Запис не включено до банків семплів. Точну схожість і баланс на акустиці
**потрібно перевірити на слух**; аналіз спектра не гарантує ідентичного тембру.
Для кожного інструмента у «Ноти та динаміка» є **Октава** від −3 до +3 (типово 0).
Значення зберігається у пресеті й додається до глобальної транспозиції;
діапазони MIDI-клавіш не зміщуються. Зміна застосовується до нових натискань,
утримані ноти завершуються зі старою висотою. Ноти поза MIDI 0–127 не запускаються.
Музичний баланс флейти з командою та роботу перемикання октави з фізичною
MIDI-клавіатурою **потрібно перевірити на репетиції**.

Плавність нижнього й верхнього країв MIDI-діапазону регулюється окремо (0–24 півтони).
0 вимикає згасання; за додатного значення крайня нота тиха, а гучність плавно
зростає всередину діапазону. Velocity та вибір семпла не змінюються.
Для вузьких діапазонів широкі зони згасання можуть зменшити гучність усього шару.

10 пресетів (редакція 5): кожен має провідний шар фортепіано або електропіано
на всьому діапазоні A0–C8, без згасання країв. Додаткові шари тихіші за основу.

| Пресет | Шарів | Призначення |
| --- | --- | --- |
| Natural Grand — чистий | 1 | Чіткий акомпанемент, Filter + Reverb |
| Felt Piano — камерний | 2 | Felt із EQ/Reverb та тихий Warm Pad із м’якою атакою |
| Warm Tine — скляний | 2 | Куплети, Chorus на клавішах, Glass у верхньому регістрі |
| Soft Grand — повітряний | 2 | Soft Grand на всій клавіатурі, тиха флейта угорі |
| Bright Grand — широкий | 3 | Bright Grand, Strings, Aurora |
| Rhodes — сяючий | 3 | Rhodes із Drive/Reverb, Shimmer, Soft Air на октаву вище |
| Felt Piano — глибокий | 3 | Felt Piano, тихі Ocean та Choir Bloom |
| Natural Grand — симфонічний | 4 | Natural Grand, струнні, хор і духові |
| Rhodes — ламповий Gospel | 2 | Rhodes із Drive/Chorus та орган із легким Drive |
| Soft Reed — насичений | 4 | Reed на всій клавіатурі, тихі Brash, орган і Warm Pad |

Використано плавні краї, октавні зміщення, до двох ефектів на інструмент.
Діапазони всіх педів і оркестрових шарів у заводських пресетах розширено вниз
на октаву: основні фони та оркестр починаються від C2, хорові — від G2,
верхні текстури — від C3. Нижні плавні краї збережено; їхні крайні ноти тихі.
У пресетах із 3–4 шарами педи мають ліміт 6 голосів і release не довше 2.5 s;
продуктивність чотирьох шарів **потрібно перевірити на цільовому ноутбуці**.
Баланс нових поєднань і переходів **потребує перевірки на фізичній MIDI-клавіатурі та акустиці**.
Основний шар кожного заводського пресету має −3 dB; гучність решти шарів
піднято пропорційно для збереження балансу. Для застосування нових рівнів
повторно виберіть заводський пресет; збережена чернетка зберігає власні рівні.
Категорії: фортепіано (4), електро-піано (4, включно з Rhodes), орган (3),
оркестр (4), прості педи (5), динамічні педи (4), ліди (5).
Прості педи: Warm, Soft Air, Strings, Glass, Ambient.
Ліди: Soft Analog, Warm Mono, Funk Butter, Gentle Flute, Brash Mono Lead.
Застарілі тембри й демонстраційний банк рояля видалено. Оновлення IndexedDB
до версії 3 одноразово очищує всі попередні користувацькі пресети й чернетку;
глобальні налаштування зберігаються. Нові користувацькі пресети зберігаються як раніше.
Оновлення до версії 4 зберігає користувацькі пресети версії 3, замінюючи Bell Keys
на Rhodes. Rhodes — легка FM-модель електропіано, не запис акустичного інструмента.

Felt Piano — окремі записи Fuchs & Möhr від Tom Guder (Public Domain),
16 опорних нот × 3 динаміки, компактна моноадаптація. Збережено акустичну
нерівність строю, про яку попереджає автор; перевірити в ансамблі на слух.

Органи Drawbar, Gospel і Reed, електропіано та ліди залишаються синтезованими.
Усі 6 простих педів, 4 динамічні педи й 4 оркестрові тембри використовують готові
семпли FluidR3 (Frank Wen, MIT) з колекції WebAudioFont. Скрипковий тембр базується
на String Ensemble, духовий — Brass Section, хор — Choir Aahs; симфонічний тембр
є заздалегідь підготовленою стереокомбінацією струнних і духових. Це компактний
GM-банк, не багатогігабайтна оркестрова бібліотека з різними артикуляціями.

Aurora Motion, Ocean Bloom, Shimmer Pad і Choir Bloom — попередньо підготовлені стереокомбінації
готових семплів педів із повільною модуляцією. Рух записано у WAV, він повторюється
в sustain-циклі та змінює швидкість при транспонуванні. Складові не синтезуються
під час гри: source + filter + envelope + expression = 4 вузли на ноту замість 30.
Атака, затухання, яскравість, панорама, гучність, sustain і pitch bend керовані.
Рух CC1 для цих семпльованих тембрів не змінює записану модуляцію.
Імпорт застарілих інструментів і форматів пресетів відхиляється без підміни тембрів.
Фанк-ліди зберігають живий синтез, mono, glide та velocity-обвідну фільтра.

Glass має початкову яскравість 4200 Hz, Soft Air — 2400 Hz, Strings — 2200 Hz;
Warm і Ambient — 400 Hz. Це застосовується при виборі
тембру або створенні шару; збережена користувачем яскравість не перезаписується.

Головний екран розраховано на desktop viewport від 1280×720: чотири шари в одному
ряду, master/пресети зверху, клавіатура знизу. Додаткові секції прокручуються
всередині картки; MIDI, керування пресетами й налаштування —
окремі вікна. На вузькому екрані ряд шарів має горизонтальну прокрутку.

Над клавіатурою показано кольорові діапазони шарів, вирівняні з реальними
позиціями білих і чорних клавіш. Приглушені та виключені Solo шари показано
тьмяно. Діапазони — вхідні ноти, тому при транспонуванні смуги не зміщуються.
Транспозиція тепер тільки глобальна, у шапці, −12…+12 півтонів. Старе поле
transpose у шарах збережено для сумісності JSON, але більше не впливає на звук.

**Ефекти шару**: максимум дві секції, включно з вимкненими. Натисніть **+**,
виберіть Filter, Chorus, Reverb, Delay, EQ або Drive. Повторний тип додати не можна.
Кожна секція має явний стан/індикатор і кнопку увімкнення; **×** прибирає секцію.
Вимкнення зберігає параметри. Щоб замінити ефект при 2/2, спершу видаліть один.
Reverb/Delay регулюються send-повзунком; їхні хвости природно затухають після
вимкнення, Panic прибирає хвости одразу.

Нові інструменти отримують помірні базові ефекти: роялі — Filter + Reverb,
електропіано та Wide — Chorus + Reverb, ліди — Delay, інші педи — Reverb.
Вибір іншого тембру встановлює його базові ефекти. Збережені значення відновлюються.
Старі пресети без rack переносять до двох ефектів у порядку Filter, Chorus,
Reverb, Delay; числові параметри решти зберігаються для повторного додавання.

Глобальну панель ефектів прибрано. EQ (низ/середина/верх ±12 dB) і Drive
(насичення зі згладженим регулюванням та компенсацією підсилення) працюють на шарі.
Вимкнені EQ/Drive звільняють обробники після короткого переходу.
Drive використовує м’яке асиметричне насичення з компенсацією підсилення,
видаленням DC нижче 18 Hz і плавним пом’якшенням високих від 3200 Hz.
Це наближення лампового характеру, не модель конкретного підсилювача.
Rhodes при виборі має Drive 28% + Reverb; у Gospel — Drive 35% + Chorus.
Збережені налаштування ефектів не перезаписуються: для нових початкових значень
повторно виберіть Rhodes або заводський пресет. Тембр на акустиці **потребує перевірки на слух**.
Reverb/Delay доступні тільки як ефекти шарів; внутрішня пара обробників спільна
для економії ресурсів, із фіксованими базовими параметрами. Старі глобальні
Reverb/Delay/EQ залишаються у JSON для сумісності, але не впливають на мікс.
Захист виходу (sample-peak limiter) і його поріг перенесено до **Налаштувань**.
Індикатор рівня звуку накладено темнішою маскою на повзунок загальної гучності.

Ліди підтримують Mono (вимкнено = poly), останню утримувану ноту та повернення
до попередньої; Glide задається в секундах. Mono повертає висоту зі snapshot
початкового натискання. CC1 додає vibrato/рух фільтра синтезу; CC11 керує expression
окремо по входу/каналу; шар може його ігнорувати. Pitch bend — 14-bit,
діапазон задається на шарі. MIDI Learn залишено етапу 4.
Глобальний Mono-вихід усереднює L/R, не додаючи +6 dB; preset recall його не змінює.

**Налаштування → Банки звуків** показують готовність у RAM, завантаження та retry. Новий 3V-банк —
16 опорних нот × 3 записані динаміки, mono 22.05 kHz, приблизно 54,9 MiB PCM.
FluidR3 містить 80 WAV-файлів: 29,63 MiB PCM.
Felt Piano додає 39,37 MiB PCM, Shimmer/Choir Bloom — 24,22 MiB PCM.
Усі чотири банки перевірено разом: 194 buffers, 148,10 MiB PCM.
Бюджет 256 MiB обмежує PCM, а не весь процес; decode rate всіх банків фіксований.
Банки завантажуються перед активацією, під час note-on мережі немає.
Natural/Soft/Bright Grand — три тональні варіанти одного банку, не три записи різних роялів.

Джерело FluidR3 зафіксоване на revision `23ca907d4370a04fd89ca483a92915e4d6159ab9`:
https://github.com/surikov/webaudiofontdata . Ліцензії, attribution, метадані джерел
і SHA-256 містяться в `public/samples/fluid-ensemble/`. У runtime не використовується
код WebAudioFont і немає зовнішніх CDN. `npm run samples:fluid` повторно завантажує
вибрані джерела й готує WAV через встановлений Playwright Chromium; тимчасові
джерела лежать у `sample-source/`. `npm run samples:verify` перевіряє всі чотири банки.
`npm run samples:worship` відтворює Felt Piano та нові педи з локального вихідного
SF2 `sample-source/felt/FuchsUndMoehrV10.sf2` і включених FluidR3 WAV.
Посилання автора, SHA-256 вихідного SF2 та опис адаптації — у
`public/samples/felt-piano/ATTRIBUTION.txt`; повідомлення FluidR3 — також у `worship-textures/`.

## Збірка та перевірки

```sh
npm run typecheck
npm run lint
npm test
npm run samples:verify
npm run build
npx playwright install chromium
npm run test:browser
```

Статичний результат — `dist/live-keys/browser`. Для підкаталогу використайте
`npm run build -- --base-href /your-path/`. Деплой не налаштовано: хостинг ще не обраний.
Поза localhost потрібен HTTPS для Web MIDI. CI повторює збірку, тести й перевірку семплів.

## Межі цього зрізу

- Компактний 3V-банк позначено demo: mono/22.05 kHz, опорні ноти переважно
  через тритон; без half-pedal, resonance і release samples. Прослуховування,
  переходи velocity та остаточне узгодження гучності ще потрібні.
- 64 голоси / опційно 32. Linked stereo sample-peak limiter без lookahead
  обмежує цифрові піки; не гарантує inter-sample/true-peak або якість аналогового виходу.
  AudioWorklet є обов’язковим; помилка його завантаження зупиняє підготовку.
- Сетлісти, MIDI Learn, Performance Mode й повні переходи зі spillover — етап 4.
- **Offline reload не реалізовано.** Після підготовки поточна відкрита вкладка грає
  з пам’яті без мережі; HTTP-кеш не дає гарантії перезапуску offline.
- Якість тембру, фізичні MIDI/sustain, реальна MIDI-to-audio затримка й тривала
  стабільність **потребують ручної перевірки**. Часткові latency API не є виміром
  затримки від клавіші до виходу. Веб-MVP для репетицій ще не оголошується готовим.

Для простих і динамічних педів у «Ноти та динаміка» є ліміт 1–32 голоси
(типово 10 на шар, зберігається у пресеті). Старі голоси при перевищенні
затухають до 0,5 с; вже коротший release не подовжується. Хвости тимчасово
існують понад ліміт; загальний аварійний ліміт рушія та Panic мають пріоритет.
«Характер звуку» відкритий одразу після ефектів.

Індикатор «Аудіо CPU» внизу сигналізує червоним протягом 2 с після виявлення
збою. Він не вимірює відсоток CPU: використовує `playbackStats.underrunEvents`,
а без цього API — приблизне відставання аудіогодинника (позначка ≈).
Короткі артефакти можуть не виявлятися; приховані вкладки та призупинене аудіо
не трактуються як перевантаження. Джерело статистики:
[Web Audio API — AudioPlaybackStats](https://webaudio.github.io/web-audio-api/#AudioPlaybackStats).
Чутливість індикатора й плавність витіснення на фізичному ноутбуці та MIDI-клавіатурі
**потребують ручної перевірки**.
